# Portofolio Fadly Alfarizy — Web & Game Developer

React + TypeScript + Tailwind CSS + Framer Motion + Lucide React (Vite).

## Menjalankan

```bash
npm install
npm run dev      # development server
npm run build    # production build ke dist/
```

## Struktur

- `src/sections/` — HeroSection, MarqueeSection, AboutSection, ServicesSection, ProjectsSection
- `src/components/` — FadeIn, Magnet, AnimatedText, ContactButton, LiveProjectButton
- `src/index.css` — global reset, font Kanit, kelas `.hero-heading`

Konten (nama, teks, layanan, proyek, gambar) ada sebagai konstanta di bagian atas tiap file section, siap dikustomisasi.
